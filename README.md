# dotfiles

personal macos config.

Window tiling is Rectangle, configured in `macos.sh`: ⌘⇧J/K left/right half
(press again to hop to the next display), ⌘⇧I/M top/bottom half, ⌘⇧H/L
previous/next display. `raycast/script-commands/rotate-tiles.sh` flips the
half-screen windows on the current display between side-by-side and stacked;
give it a hotkey in Raycast.
